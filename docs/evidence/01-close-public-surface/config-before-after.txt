=== 2. Route cua gateway: HTTP status ===

Chay gateway that bang:
  docker run --rm -p 127.0.0.1:18080:80 -e PUBLIC_ADDRESS=:80 \
    -e GATEWAY_BASIC_AUTH_USER=ops -e GATEWAY_BASIC_AUTH_HASH='$2a$14$...' \
    -v <Caddyfile>:/etc/caddy/Caddyfile:ro caddy:2.8-alpine
